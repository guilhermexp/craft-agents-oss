# Craft overlay

This directory is synchronized from
`injaneity/pi-computer-use@8e1772f317dedd3a77d34835c970d92cd5b887ae`
(`package.json` 0.5.0). The immutable source pin is also stored in
`UPSTREAM_COMMIT`.

Craft keeps only the published runtime sources and assets needed by the
embedded macOS Pi backend. Upstream repository metadata, CI configuration,
demos, release notes, development-only checks, lockfiles, and caches are not
vendored.

## Overlay files and edits

- `skills/computer-use/SKILL.md` is Craft-owned operational guidance for the
  stateful v0.5 tool contract.
- `extensions/computer-use.ts` keeps the upstream `ExtensionAPI` type import,
  defines the upstream identity-only `defineTool` helper locally, and uses
  Craft's existing `@sinclair/typebox` schema builder. `src/config.ts` mirrors
  Pi's small agent-directory resolution locally. Together with the build-time
  external marker for type-only SDK imports, these edits prevent the runtime
  bundle from embedding or resolving a second copy of the Pi SDK or TypeBox's
  unrelated development toolchain.
- `package.json` points Pi at
  `src/platform/macos/craft-runtime-extension.js`, the generated self-contained
  extension entry, and includes the Craft skill in its published file list.
- `src/platform/macos/helper.ts` exports its resolved package root and setup
  script path so the isolated test can verify the bundle-location invariant.
- `scripts/craft-stage-runtime.mjs` stages only `package.json` plus its explicit
  `files` allowlist, preventing caches, lockfiles, dependencies, or upstream
  development artifacts from leaking into `dist`.
- `src/platform/macos/craft-runtime-extension.js` is generated by
  `bun run build:computer-use-extension` from the upstream TypeScript entry.
  The vendored source is excluded from Craft's stricter monorepo typecheck just
  like `pi-better-subagents`; the pinned upstream owns its source typecheck,
  while Craft validates the generated entry by loading it in isolation. Its
  location intentionally preserves the package-root calculation used by
  the macOS helper code after bundling.

The generated entry bundles the small schema builder and all computer-use
TypeScript runtime modules. Its only remaining imports are Node built-ins, so loading the package
never falls back to the monorepo `node_modules`. The isolated loader regression
test deterministically rebuilds and compares the generated entry, then proves
its import boundary, package-root/helper resolution, and actual tool
registration from a tree outside the checkout.

- `package.json` explicitly publishes all three macOS Swift sources required by the source-build fallback without including compiled native artifacts.
- `package.json` declares `skills/computer-use/SKILL.md` in the Pi manifest so package-manifest discovery loads the Craft skill.
- `scripts/setup-helper.mjs` limits imported signing-key access to `/usr/bin/codesign` and runs `--postinstall` setup only when `PI_COMPUTER_USE_POSTINSTALL=1`.
- `package.json` removes scripts for non-vendored typecheck/test files and their now-unused TypeScript-only development dependencies while preserving runtime/native build scripts.
