# v0.8.13 — Slack-like channel War Rooms with agent participants

## Features
- **Channels now behave like shared War Rooms instead of simple session labels** — A channel has its own visible room log, configured participants, and per-agent routing while individual agent sessions remain implementation details behind the shared conversation.
- **Agent participants can be added from the channel UI** — Empty channels expose an inline “Add agent” flow so users can configure a participant id/mention, display name, LLM connection, optional model, and optional Hermes profile without editing `channels/config.json` manually.
- **`@` mentions now route messages to channel participants** — The composer shows mention autocomplete for configured participants, accepts the highlighted mention with `Tab` or `Enter`, and sends targeted messages to the matching agent participants.
- **Hermes lead/orchestrator sessions can dispatch to Craft-native participants** — Channel-bound Hermes sessions receive the `mcp__session__channel_dispatch` tool, allowing a lead/orchestrator to call another participant in the same channel, including native Claude/Pi-style connections, and return results to the same room.
- **Dispatch status is persisted and visible** — Channel dispatch records are stored append-only in `channels/dispatches/<channelId>.jsonl`, exposed through channel-scoped RPCs, and surfaced in the conversation panel so queued/running/completed/failed work is no longer silent.

## Improvements
- **Channel routing is more forgiving for lead/orchestrator rooms** — If no explicit `leadParticipantId` is configured, the router now picks the first Hermes participant, then the first participant, instead of leaving the room unusable.
- **Unknown mentions and agent failures are shown to the user** — The channel UI now reports targeted agents, unknown mentions, per-agent failures, and recent dispatch state so a posted message has visible routing feedback.

## Developer Notes
- The maintenance contract for this feature lives in `apps/electron/docs/channels-war-room.md`.
- Core files include `packages/shared/src/channels/dispatches.ts`, `packages/session-tools-core/src/handlers/channel-dispatch.ts`, `packages/server-core/src/channels/channel-orchestrator.ts`, `packages/server-core/src/handlers/rpc/channels.ts`, and `apps/electron/src/renderer/components/app-shell/ChannelConversationPanel.tsx`.

## Breaking Changes
- None. Existing channels and sessions remain compatible; the new dispatch state is additive and channel-scoped.
